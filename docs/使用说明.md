# 使用说明（给销售 / 外贸 / 报价岗）

> 不用装软件，不用记命令。双击 `启动.bat`，浏览器打开就能用。
> 界面支持 10 种语言（中 / 英 / 西 / 葡 / 阿 / 俄 / 印尼 / 越 / 泰 / 土），给客户的资料是中文 + 英文双语。

---

## 1. 打开

1. 双击文件夹里的 **`启动.bat`**。
2. 浏览器自动打开 `http://127.0.0.1:8765/index.html`。
3. 关掉那个黑色窗口 = 关闭系统。

打不开时：直接双击 `index.html` 也能用（少了本地服务，功能基本一致）。

### 1.1 第一次打开会问你两件事

**先选界面语言**（10 种，选完记住；顶部右上角随时能换，阿拉伯语自动从右往左）。首页那 5 个示例句会跟着语言换成当地客户的说法（西语 `HOWO A7 pastillas traseras 200 pzas`、俄语、阿语……），点一下就进选型。

**再登录**（登录窗默认只显示客户登录，员工 / 老板入口是隐藏的）：

| 你是谁 | 怎么登 | 登进去能看到 |
|---|---|---|
| **客户** | 选联系方式类型（WhatsApp / 手机 / 邮箱 / 微信 / Telegram），填号码或邮箱，再填称呼、公司、国家（可空） | 只能看选型、产品库、参考价，以及**属于他自己的**报价单和资料包 |
| **体验版客户** | 什么都不用填，点一下「⚡ 体验版 · 客户」 | 直接进客户版，所有功能都能试；顶栏显示「体验版 · 客户」，员工端会单独标出来 |
| **员工** | **先在登录窗顶部（Logo + 标题那块）双击**解锁入口，再选「员工」，输入访问码 `GY2024`（`assets/auth.js` 里 `STAFF_CODE` 可改），填个名字 | 全部页签，外加**客户浏览**：客户搜了什么、看了哪些型号、开没开报价单 |
| **体验版员工** | 双击解锁后点「⚡ 体验版 · 员工」，不用访问码 | **只读**：全部页签都能看、客户浏览能翻，但发送、导入、保存报价、改数据都被挡住 |
| **老板 / 体验版老板** | 同样双击解锁，再选「老板」（老板码 `GYBOSS`）或点「⚡ 体验版 · 老板」 | 员工业绩、成交、转化与产品结构；登记类操作被禁用 |

客户用哪个联系方式登录，后面报价单和资料包就填谁；员工点「发送」会直接拉起对应的 WhatsApp 或邮件。

> 员工 / 老板入口只在本次打开期间解锁：**退出登录会自动收起**，回到纯客户登录；要换身份，再双击一次登录窗顶部即可。

## 2. 最常用的一条路径（记住这四步）

```
输入客户原话  →  看候选型号和依据  →  加入报价  →  生成报价单 / 资料包
```

顶部搜索框随便输入，回车：

- `豪沃A7 后片 200套`
- `解放J6P 457桥 后片`
- `58144-45211`（只有一个编码也行）
- `BPW TS2 370 盘片`
- 甚至客户的原话：`Tenemos 480 unidades HOWO A7, necesitamos pastillas traseras`

| 成交台账 | ❌ | ✅ 登记单子、改成交状态 |

| 用户画像 | ❌ | ✅ 画像 + 客户搜索 + 获客内容，一个入口三段切换 |
| 编号对照 | ❌ | ✅ WVA / FMSI / OE / 车桥 → 自家型号 |
| 询盘线索 | ❌ | ✅ 跟进状态、下一步动作 |
| 适配图谱 | ❌ | ✅ 车型 → 车桥 → 型号 |

| 转单云（外部） | ❌ | ✅「客户管理」菜单最后一项，新窗口打开 `admin.hqsmartcloud.com` 的转单云后台 |

## 4. 页签逐个说

### 工作台 / 首页
- 打开就是**官网样式**：顶部大图（有视频就播视频，没有就播 4 张海报复轮播）、关于冠英、产品类别、工具入口、新闻、联系我们。
- 大图下面那条搜索框最常用：输入客户原话直接选型，比一层层点菜单快。
- 点「产品类别」任意一张卡（鼓式衬片 / 盘式刹车片 / 风电刹车片）→ 直接跳到产品库并筛好类。
- 视频：把 `hero-1.mp4`、`hero-2.mp4` 放进 `assets\video\` 文件夹，刷新即生效。大图**默认完整显示**（不裁边），如果视频两侧留黑边，点右下角 `⛶` 切成「铺满」；再点一次切回来，选择会记住。
- 再往下才是「现在该联系谁」「最近浏览」和「为什么车型锁不住型号」。

### 智能选型（核心）
1. 输入 → 点「解析并选型」。
2. 看顶部**识别结果**：系统把你这句话拆成了车型/车桥/编码/数量，并标出命中了什么。
3. 看**候选型号**：每个都有匹配分（≥90 可直接报价，≥75 高置信，<75 先问清楚）。
4. 看**常用车型 · 按点赞量排序**：这个型号装哪些车、哪款车在社媒上被讨论得最多。前三名标了 🥇🥈🥉，每行给出车桥、部位、对应型号、内容条数和点赞合计。点赞高的车型 = 关注度高 = 优先备货、优先做内容。
5. 看**还差一步就能锁定**：这就是你要问客户的那句话，直接复制发过去。
6. 识别到车型时，下面会出现**车桥对应表**：一个车型可能对应 2–3 个型号，让客户确认桥型。

右侧「现场三步定位法」是给销售背的话术：**问桥不问车 → 拍三张照 → 数孔**。

### 产品库
按型号 / 编码 / 名称搜，或按品类、品牌线、材质筛。
每行左边都有**缩略图**（272 个型号全部有图；万一图片文件缺失会自动显示占位图，不会出现空白框）。
「常用车型/车桥」列能直接看出这片装什么车；「车型赞」列是它覆盖车型的相关内容点赞合计。
右上「排序」可以选**按点赞量**——一眼看出哪个型号、哪个车型最受关注。
点任意一行看详情：图片、规格、编码对照、**常用车型热度榜**、试验报告。
右上「导出 CSV」可给 IT 或做二次加工。

> 车型榜两类来源：标了置信度的是已建档的适配关系；标「推断」的是官网标题里写明的品牌/车系（尚未逐车型确认，报价前按旧件或车桥核对即可）。

### 适配图谱
左边车型树，展开看「车型 → 车桥 → 型号」。
右边车桥主数据 + **待复核队列**。
新增关系点右上按钮，填完保存 → 进入待复核，不会立刻对外生效。

### 报价单
1. 客户与条款：选客户（自动带出等级、付款方式、贸易术语）。
2. 明细：改数量、换材质，单价与金额自动重算。
3. 右侧看货值、运费估算、合计。
4. 右上角两个按钮，**大的那个是「报价」，小的那个是「生成报价单」**：
   - **报价（大）**：点开逐个型号改单价（系统已按阶梯价填好），下面实时算合计，可写一句备注（如「价格 30 天有效，FOB 上海」）→ 点「发给客户」。客户登录后在右下角「客服解答」里就能看到这张报价单和金额。
   - **生成报价单（小）**：预览 → 打印 / 另存为 PDF，用于发邮件或存档。
5. 客户端的报价页还是「询价 + 生成报价单」，看不到发价按钮——发价是员工的动作。

**阶梯价**：数量越多单价越低（100 / 300 / 1000 三档），客户等级再乘系数。系统都算好了，不用背。

### 资料包
勾选要打包的内容 → 「生成并打印」出多页 A4（封面 + 报价 + 每个型号一页 + 试验 + 确认页），或「下载 ZIP」发微信/邮件。
客户说「把资料发我」时，30 秒搞定。

### 询盘线索
- 列表按评分排序：终端特征加分、贸易商特征扣分，评分依据点开就能看。
- 「当地时间」列告诉你现在能不能联系。
- 点一行看详情：原文、中文摘要、自动匹配的型号、状态和下一步。
- 「生成回复」按客户询盘自动填好，复制即用。

**止损线**：名字带 Trading / Import & Export / FZE 且拿不出终端地址的，只发目录；只问价不给车型的，报价即可，不做方案。

### 增加客户（员工端专属）

导航「客户管理」菜单的第一项。两种录法：

- **手动录入**：姓名\*、公司、国家、联系方式类型 + 号码\*、标签、备注 → 「保存客户」。
- **拍照名片**：手机端点「拍照」直接调相机（桌面可上传图片）→ 预览 → 「识别名片」→ 自动带出姓名 / 公司 / 国家 / 联系方式 → 左边核对后可改 → 「保存客户」。
- 联系方式按号码 / 邮箱归一化比对：已经存在的客户会**更新**，不会建重复档案。
- 保存后立刻出现在「客户浏览」和客户列表里，可一键发 WhatsApp / 邮件、加入询盘池。

> **识别目前是演示数据**：没接 OCR，点「识别名片」会填一组可改的示例字段。接上腾讯云 / 阿里云 OCR 或 GPT-4o 后，把 `addCustOcr` 里填字段那段换成接口返回即可读真名片，前端流程不用改。

### 用户画像（获客的总入口）

导航里只有「用户画像」一个入口，进去顶部一条分段条：**用户画像 ｜ 客户搜索 ｜ 获客内容**，点一下互切，导航始终停在「用户画像」上。

- **用户画像**（默认）：关系网 + 按意向度排序的账号列表，见下。
- **客户搜索**：检索式找终端客户，见「客户搜索」一节。
- **获客内容**：短视频选题与脚本，见「获客内容」一节。
- 前端首页「工具入口」里的卡片也合成了一张「用户画像」，三段都从这里进。

- 关系网图：点任意节点看账号画像。
- 右侧按意向度排序，先打高分。
- 画像卡里有「提到车型 → 可推型号」，以及推荐动作（寄样 / 私信 / 视频置换）。
- 「生成私信」按该账号市场语种出草稿。

#### 用户画像 · 获客内容（分段条第 3 段）

在「用户画像」页点分段条第 3 段「获客内容」进入。

- 上半是**热门视频雷达**：哪个语种、什么选题、为什么火、能挂哪个型号。
- 点「用此选题」或「生成脚本」→ 带出市场、语种、型号，下方直接出分镜稿 + 口播 + AI 提示词。
- 脚本 = 6 个分镜 + 目标语种口播 + 标签 + 拍摄清单。
- 提示词下面就是「去 Kling AI 生成视频」：先「复制提示词」，再点开 [Kling AI](https://kling.ai/) 粘贴，按这个脚本出片。
- 「复制 AI 提示词」→ 也可以粘到任意大模型，让它润色成母语版本。

### 客户询价（员工端专属）
客户在客户端点「询价」提交的清单会出现在这里，不用等他把消息发到 WhatsApp：

- 每行一条询价：时间、客户（体验账号有黄色 `体验` 标签）、询价号 `RFQ-20261121-001`、要的型号和数量、留言、联系方式。
- 点「载入报价」→ 这些型号和数量直接进报价单，改价、加运费、生成 PDF，一步不用重录。
- 点「履历」→ 看这个客户之前搜过什么、看过哪些型号。
- 客户那边会收到一个询价号，提示「2 小时内回复到这个联系方式」。

### 数据导入
- 选类型 → 粘贴 CSV → 校验并导入（会逐行报错，告诉你第几行哪里不对）。
- 「导出全量快照」= 备份；「恢复默认数据」= 回到出厂状态（慎用）。
- 右侧「字段字典」是给 IT 看的表结构说明。

### 客户浏览（员工端专属）
客户的每一次登录、搜索、看型号、加报价、开资料包都会记下来。这一页告诉你**谁在真正选型、谁只是路过**：

- 顶部四个数：24 小时内活跃、累计浏览型号、打开报价/资料包的次数、高意向待跟。
- 列表按最近活跃排序：左边客户名和公司，中间是他的联系方式，右边浏览/搜索/询价次数和**意向评分**。
- 点一行进详情：他搜过的原话、看过的型号（可点开）、按天分组的浏览轨迹。
- 下面有一个已经写好的消息框，点「用 WhatsApp 发送 / 用邮件发送」直接拉起客户端，内容可以改了再发。
- 「加入询盘池」把这个人一键变成线索，评分和搜索词一起带过去。

> 目前记录存在**本机**（同一台电脑、同一个浏览器）。要让客户在他自己手机上浏览、你在办公室看到，需要下一步加一个小服务端；界面和数据结构已经按那个样子做好了。

#### 用户画像 · 客户搜索（员工端专属）

导航「用户画像」→ 分段条第 2 段「客户搜索」。

按「产品词 + 客户类型 + 国家/语言」生成可以直接投喂搜索引擎的检索式，不用自己想关键词。

- **五个参数**：市场（12 个，自带本地语言）、产品（盘式/鼓式/制动蹄/风电）、客户类型（经销商/进口商/批发商/车队/修理厂）、收窄方式（site: / intitle: / inurl: / filetype:pdf）、排除词。
- **一次生成 7 条检索式**：
  1. 组合公式（产品词 + 客户类型 + 国家域名）
  2. WVA 号式（取你目录里真实的 29xxx 号）
  3. FMSI 号式（鼓式形状码 + PDF 目录）
  4. 本地语言式（pastillas de freno / pastilha de freio / فحمات فرامل …）
  5. 车桥/卡钳式（BPW / SAF-Holland / Meritor / Fuwa）
  6. 车队维保式（intitle:fleet）
  7. 地图式（Google Maps 按城市找门店）
- 每条后面有 **Google / Bing / Yandex / Maps** 四个按钮，点开即搜；「复制全部」一次拿走。
- 底部「③ 搜到的人，回填成线索」：填公司名、国家、来源链接 → 一键进「询盘线索」，后面照常打分、匹配型号。
- 展开「筛客户的 4 条硬规则」：近 12 个月、≥4 票且间隔稳定、抓切换信号、别信 notify party / 别只按 HS 编码。

**④ 预设库（按区域，16 组）**：已经跑过的一批检索式，按东南亚 / 中东 / 南美 / 北美 / 欧洲 / 南亚 / 俄语区 / 非洲分好，每组标注了本地语种锚点、主渠道、漏单原因。

- 两种模式切换：**短版**（DDG / Serper，可直接喂脚本）↔ **长版**（Google 全语法，带 `site:` `filetype:pdf`）。
- 每条都能单独复制、或直接开 **Google / Bing / Yandex / DDG**。

**怎么验证这些检索式真的能搜到人**（3 分钟）

1. **先复现**：用户画像 → 客户搜索 → 滚到「④ 预设库」→ 点「复制全部 16 组」，粘到记事本里对照。
   当前正确版本应该是：**8 个区域 / 16 组 / Google 段 32 行 / DDG 段 16 行 / 锚点 8 行**。
   如果你手里那份只有 6 个区域（缺「南亚 SAS」「俄语区 RU」）、DDG 只有 12 行，那是旧版，重新复制一次即可。
2. **逐条点开看**：每条右边有「Google / Bing / Yandex / DDG」按钮，点一下就是真搜索结果页。
   - 看**结果里是不是终端客户**：出现 fleet / workshop / garage / truck service / 修理厂 这类词才对；整屏都是 alibaba、made-in-china、tradekey，说明排除词没生效。
   - 看**本地语种词有没有命中**：南美搜 pastilha de freio，应该出巴西本地汽配店、车队；只出英文结果说明关键词不对。
   - 看**PDF 目录**：长版带 filetype:pdf，正常会搜到对方的产品目录、联系方式页。
3. **长版和短版别混**：site: / filetype: / (A OR B) 这套长语法**只有 Google、Bing 认**，DDG 会静默忽略——不是坏了，是它的语法限制。所以「短版」给 DDG / Serper 用，「长版」给 Google 用。
4. **搜到人之后**：回到本页底部「③ 搜到的人，回填成线索」，填公司名 + 国家 + 来源链接 → 进「询盘线索」，后面照常打分、匹配型号。

> 搜索结果是外部网站的实时内容，不同时间、不同地区、登不登录都会不一样，同一句你搜和我搜可能差几条——看的是「有没有搜到这类公司」，不是逐字一致。
- 「复制全部 16 组」按原来的格式输出：带 `#` 注释的 Google 段 + DDG 段 + 本地语种锚点段，可直接粘回脚本或文档。

### 成交台账（员工端）

- **点表格里任意一行，会弹出这一单的完整信息**：
  - 顶部：客户名、国家、登记人、状态标签；
  - 三个大数字：成交金额、数量、单价（金额 ÷ 数量，自动算）；
  - 明细：型号、产品名、日期、状态、国家/市场、记录号、备注；

## 5. 右下角「客服解答」（两个端不一样）

同一个浮窗，客户和员工看到的内容不同：

**客户看到的**（问答式）
- 一句「需要什么帮助？」+ 两个示例问题（豪沃A7 后片 200套 / 457桥 100套），点一下直接问

## 9. 常见问题

**Q：为什么搜「J6」出来好几种？**
A：J6 系列后桥有 457/485/498 三种，片不通用。这正是系统要帮你问清楚的地方，不是库不准。

**Q：客户只发一张照片怎么办？**
A：让他把旧片放平、旁边放把卷尺再拍一张；或拍车桥铭牌。拿到孔数和厚度，命中率立刻上去。

**Q：报价和公司实际价格不一致？**
A：现在库里的价格是演示基准价。让报价岗把真实价格表整理成 CSV，在「数据导入」里选「产品更新」导入即可。

**Q：资料包里的图打不开？**
A：图片在本机 `assets/img/p/` 里，用「打印 → 另存 PDF」会带图；ZIP 里是网页+CSV，图片请用打印版。

**Q：能不能只给某个客户看某几个型号？**
A：可以。加入报价时只加那几个，再生成资料包即可。
