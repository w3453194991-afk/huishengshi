# 冠英 · 选型与报价中台

> 一句话：把客户嘴里的「车型 / 车桥 / 旧件编码」，在 10 秒内变成**型号 + 依据 + 报价 + 可直接发走的资料包**。

零安装、离线可用。双击 `启动.bat`（或直接打开 `index.html`）即可使用，不需要服务器、不需要联网。

**两个入口**（首次打开先选语言，再选身份）：

| 入口 | 怎么进 | 能看到什么 |
|---|---|---|
| 客户 | 用**任意联系方式**登录（WhatsApp / 手机 / 邮箱 / 微信 / Telegram / Viber），填个称呼即可 | 选型、产品库、参考价、自己的报价单与资料包；看不到内部线索、成本和别人 |
| 体验版·客户 | 点「⚡ 体验版 · 客户」，什么都不用填 | 客户版的全部功能，顶栏标「体验版 · 客户」 |
| 体验版·员工 | 点「⚡ 体验版 · 员工」，不用访问码 | 全部 14 个页签**只读**：能看客户浏览，发送/导入/改数据被禁用，顶栏有横幅提示 |
| 员工 | 访问码 **`GY2024`**（在 `assets/auth.js` 顶部可改） | 全部页签 + **客户浏览**：客户搜了什么、看了哪些型号、有没有打开报价单，可直接按他的联系方式发消息 |

> 客户登录后，报价单/资料包自动填成他本人；员工端点「发送」会拉起 WhatsApp 或邮件客户端，内容可先改再发。

## 1. 现在就能回答的三个问题

| 客户怎么说 | 系统怎么答 | 在哪 |
|---|---|---|
| 「我这车用哪个刹车片？」 | 先给候选集 + 3 个消歧问题（什么桥 / 几孔 / 拍张照），不是瞎猜一个型号 | 智能选型 |
| 「HOWO A7 后片，200 套多少钱？」 | 型号 + 阶梯价 + 运费估算 + 一张可打印报价单 | 智能选型 → 报价单 |
| 「把资料发我」 | 封面 + 报价 + 产品数据页 + 试验报告 + 发货确认页，一次生成，可打印 PDF 或打包 ZIP | 资料包 |

## 2. 30 秒上手

1. 双击 **`启动.bat`** → 浏览器自动打开 `http://127.0.0.1:8765/index.html`
   - 服务在**后台静默运行**，不用保持任何黑窗口；要关闭服务双击 `停止.bat`
   - 没有 Node/Python 也能用：脚本会自动改为直接打开 `index.html`（功能基本一致）
   - 如果浏览器报「127.0.0.1 拒绝连接」= 后台服务没在跑，双击 `启动.bat` 即可（脚本会等端口起来再开页面）
2. 顶部搜索框输入 `豪沃A7 后片 200套`，回车 → 看候选型号、依据链和报价
3. 点「加入报价」→ 切到「报价单」→「生成报价单」→ 浏览器打印里选「另存为 PDF」

键盘：`Ctrl/Cmd + Enter` 开始匹配，`Esc` 关弹层。

## 3. 十四个页签

| 页签 | 作用 |
|---|---|
| 工作台 | 今日待处理询盘（按时区排序）、数据健康度、为什么「车型锁不住型号」 |
| 智能选型 | 车型/车桥/编码/客户原话 → 候选型号 + 消歧问题 + 报价依据 |
| 产品库 | 272 个型号，含**常用车型/车桥**、规格、材质、编码数、参考价；可导出 CSV |
| 适配图谱 | 车型 → 车桥 → 型号 的关系树；新增关系进「待复核」队列 |
| 报价单 | 阶梯价自动计算、客户等级系数、运费估算、保存/载入历史报价 |
| 资料包 | 多页 A4 文档：封面 + 报价 + 产品页 + 试验 + 确认页；打印 PDF 或下载 ZIP |
| 询盘线索 | 线索评分（终端/贸易商识别）、当地时间、状态流转、一键匹配型号 |
| 客户浏览 | **员工端专属**：客户登录后的浏览轨迹、意向评分、按联系方式一键发送 |
| 客户询价 | **员工端专属**：客户在前台点「询价」提交的型号+数量+留言，一键载入报价单 |
| 用户画像 | **获客总入口**，三段切换：① 画像（关系网/意向排序/私信草稿）② 客户搜索（检索式找终端买家 + 16 组预设库）③ 获客内容（各语种热门视频雷达 → 短视频脚本 + AI 提示词 → 一键跳 Kling AI 出片） |
| 成交台账 | 记一笔成交、改状态、点行看详情；老板端汇总业绩 |
| 编号对照 | WVA / FMSI / OE / 车桥 → 自家型号，缺什么一眼看到 |
| 短视频接口 | RedFox 短视频数据（TikTok / IG / YouTube）→ 选题与线索 |
| 数据导入 | CSV 粘贴导入（适配/产品/线索/编码）、全量快照导出、恢复默认 |

> 员工导航「客户线索」菜单的最后一项是外部入口 **转单云**（https://admin.hqsmartcloud.com/#/home），新窗口打开，不属于本站页面；客户登录看不到。

右下角常驻 **客服解答**：模拟/接入聊天消息 → 识别车型 → 浮窗提醒型号与价格 → 一键复制回复。

## 5. 数据：来源、规模、边界

| 项 | 数量 | 来源 |
|---|---|---|
| 产品型号 | 272 | kooying.com 产品目录（公开页） |
| 编码/别名 | 613 | 型号本身 + 目录中的 WVA/工厂码/OE 号 |
| 车型 / 车桥 | 26 / 14 | 人工整理（豪沃、J6P、天龙、德龙、BPW、富华、SAF…） |
| 适配关系 | 44 | 人工整理，**全部带置信度与来源** |
| 试验报告 | 12 | 示例结构（GB 5763 / ECE R90 / SAE J661 / ISO 15484） |
| 客户 / 线索 | 8 / 8 | 演示数据 |

**必须说清楚的三件事：**

1. **价格、MOQ、交期、客户名、试验报告号是演示数据**，不是公司真实报价。上线前请用真实价格表替换（产品库 → 导出 CSV → 改价 → 数据导入）。
2. **适配关系目前 0 条「已确认」**：16 条高、23 条中、5 条低。系统里每一条都标了置信度和来源，并进入「待复核」队列——这是诚实的做法，也是这个库能长期用下去的前提。
3. 尺寸（`规格`）还有缺口，是当前最该补的一项：补上它，「拍照+卷尺」就能直接定型号。

自带一个**纠错闭环**：销售在「适配图谱」新增关系 → 进待复核队列 → 研发确认后变「已确认」→ 下次匹配的置信度自动提高。

## 6. 重新生成数据

```bat
cd /d E:\湖北\冠英数据中台
node build\build-data.mjs     :: 官网/知识层 → assets/data.js + data/db.json
node build\make-db.mjs        :: → data/guanying.db
python build\make_xlsx.py     :: → data/导入模板.xlsx
```

日常改数据不需要跑脚本：直接在「数据导入」里粘贴 CSV，改的是本机浏览器存储（`localStorage`），可随时「导出全量快照」备份，或「恢复默认数据」回滚。

## 7. 常见问题

**双击后浏览器没打开？** 手动打开 `index.html` 也行；或地址栏输入 `http://127.0.0.1:8765/index.html`。

**改了数据，换台电脑就没了？** 正常。本机数据存在浏览器里；要多人共用，请把 `data/guanying.db` 接进公司服务器（表结构已按多用户设计，见 `docs/方案说明.md` 第 6 节）。

**打印出来图片是空白？** 打印对话框里勾选「背景图形」，并把缩放设为「默认」。

**能接孚盟 CRM / 进销存吗？** 能。`data/guanying.db` 是标准 SQLite，字段见「数据导入 → 字段字典」；或每天导出 CSV 对账。
